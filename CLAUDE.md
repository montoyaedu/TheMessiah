# Istruzioni per l'assistente

- **Dopo ogni passo di lavoro** aggiungi una voce datata in testa al `README.md`,
  nella sezione "Ultimi lavori" (tra i segnaposto `DIARIO`), la più recente in
  alto: cosa è cambiato, perché, cosa resta non verificato. Quando le voci
  superano la decina, sposta le più vecchie in `docs/diario.md`.
- Se cambiano le partiture, lancia `make pubblica` (ricompila, copia i PDF in
  `pdf/` e aggiorna la tabella del README).
- Di' sempre se una nota è letta (da quale fonte), dedotta o non verificata.
- Le letture dalle scansioni vanno fatte controllare da un lettore indipendente
  prima di darle per buone.
- Scrivi in italiano nei file del progetto.
