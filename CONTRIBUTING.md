# Contribuire

Le indicazioni sono nel README: [Come contribuire](README.md#come-contribuire).

In breve, per ogni contributo (di una persona o di un assistente AI):

1. aggiungi una voce datata in testa al README, in
   [Ultimi lavori](README.md#ultimi-lavori): cosa è cambiato, perché, cosa non è verificato;
2. di' se ogni nota è letta (da quale fonte), dedotta o non verificata;
3. usa solo fonti di pubblico dominio o con licenza compatibile, e citale.
